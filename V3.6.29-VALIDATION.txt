Fara Xray v3.6.29 - portable backup validation
================================================

Base version: 3.6.28
Target version: 3.6.29

Implemented:
- SQLite backups are created from a temporary consistent snapshot.
- Only upstream/core 3x-ui model tables are retained in the downloadable snapshot.
- Fork-only analytics/history tables remain untouched in the live database.
- The disposable snapshot is VACUUMed to reclaim freed pages.
- PRAGMA integrity_check is required before the backup is returned.
- Existing SQLite restore/import flow is intentionally preserved.
- PostgreSQL backup behavior is intentionally unchanged.
- Added a database regression test that creates an extra fork-only table and verifies it is removed while all required upstream tables survive.
