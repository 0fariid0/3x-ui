راهنمای انتشار نسخه 3.6.31
===========================

فایل ZIP کامل این نسخه همراه یک اسکریپت Git Bash مستقل تحویل داده می‌شود.
اسکریپت انتشار پیش از جایگزینی فایل‌ها این موارد را کنترل می‌کند:

- SHA-256 دقیق فایل ZIP
- وجود مخزن Git و تمیز بودن working tree
- همگام بودن main با origin به‌صورت fast-forward
- ساخته‌نشدن قبلی تگ v3.6.31 روی GitHub
- معتبر بودن ساختار ZIP و مقدار 3.6.31 در internal/config/version
- موفق بودن git diff --cached --check

همچنین پیش از جایگزینی سورس، یک backup branch زمان‌دار روی origin می‌سازد.
پس از عبور از کنترل‌ها، main را Push می‌کند و تگ annotated نسخه v3.6.31 را
می‌سازد تا گردش‌کار Release مخزن اجرا شود.

نام فایل‌های تحویلی:

- 3x-ui-v3.6.31-complete.zip
- 3x-ui-v3.6.31-git-release.sh

اسکریپت را در Git Bash ویندوز اجرا کنید. مسیر پیش‌فرض مخزن در آن:

  /c/Users/ASREJADID/github-projects/3x-ui

اگر پروژه در مسیر دیگری است، فقط مقدار REPO را پیش از اجرا ویرایش کنید.
