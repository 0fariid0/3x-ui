Fara Xray v3.6.25 - validation report
=====================================

Validated changes:
- Version identifier: 3.6.25.
- Multi-inbound online state now uses an exact panelGuid -> email -> inbound-tag map.
- The old aggregate active-inbound set is no longer used by the v3.6.25 frontend to decide a client's per-inbound online badge.
- Exact attribution is propagated through remote-node traffic snapshots.
- Client usage details show Connected Inbounds and no longer present every host/IP choice as if it were used.
- Legacy host rows no longer receive the client's generic last-traffic timestamp.
- A bounded transient Xray access log is generated when administrator access logging is disabled; it is tailed every 5 seconds and truncated after complete ingestion.
- Regression tests were added for cross-client/cross-inbound leakage, exact-map grace handling, and node-tree scoping.
