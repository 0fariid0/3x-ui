Fara Xray v3.6.6 validation report
==================================

Base
----
- Built from the complete custom v3.6.5 source tree.
- internal/config/version is 3.6.6.

Implemented
-----------
- Unified Gregorian/Jalali date rendering across client reports, system history,
  Xray metrics/logs, dashboard alerts, and chart labels.
- All absolute timestamps use the panel-selected server/Tehran offset instead of
  the administrator browser timezone.
- Added exact rolling 12-hour and 24-hour client-usage reports with hourly upload
  and download timelines.
- Preserved configurable daily ranges from 7 through 365 days.
- Reworked dashboard high-consumer alerts into a compact text-only layout without
  consumption progress bars and with direct client-report navigation.
- Placed compact Xray/system uptime information beside usage alerts on desktop.
- Added minute, hour, and day traffic rollups with bounded retention and migration
  of existing v3.6.5 minute history.
- Raw minute records are retained for 25 hours, hourly rollups for 31 days, and
  daily rollups for the configured report retention with a hard 365-day ceiling.
- Insight cleanup runs hourly and includes SQLite WAL checkpoint/optimization.
- Panel, Xray, and IP-limit logs now use strict small-file retention limits suitable
  for a 40 GB server.
- Generated TypeScript, Zod, JSON Schema, examples, and public OpenAPI were regenerated.

Validation completed
--------------------
- All Go source files parsed successfully with go/parser.
- Changed Go files are gofmt-clean.
- Changed TypeScript/TSX and generated files passed isolated TypeScript syntax transpilation.
- Persian/English translations, package.json, and public OpenAPI JSON parse successfully.
- CSS brace checks passed for all changed dashboard/report stylesheets.
- install.sh, update.sh, and x-ui.sh pass bash syntax validation.
- Replacement simulation from the complete v3.6.5 source passes git diff --cached --check.
- Rolling 12-hour report regression coverage was added.
- OpenAPI generation completed: 42 schemas, 172 paths, 176 operations, and 12 tags.

Environment limitation
----------------------
- Full dependency-aware Go tests and the complete Vite production build were not run locally.
  This environment has Go 1.23.2 and Node 22, while the repository requires Go 1.26.5 and
  Node 24, and the required external dependencies/toolchains could not be downloaded.
  GitHub Actions remains the final full build and test check after pushing tag v3.6.6.
